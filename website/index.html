02 / Features

What it does. In eight parts.

Some details differ between macOS, Linux, and Windows, and the inspector can only show what the system allows.

  1. Process tree tree

    Processes are shown with their parents and children. Rows keep their place while the values update.

  2. Tree lock lock

    Lock the tree to freeze the order while you look at something. The values keep refreshing.

  3. Search and filters search

    Search by name, PID, or path. Matches are highlighted and the rest of the tree stays visible. A search can be saved as a filter.

  4. Metrics and history metrics

    CPU, memory, network, and storage per process and per subtree, with history charts. Hover a chart to read a sample.

  5. Inspector inspect

    Open files, sockets, threads, and security details for the selected process. When the system denies access, the inspector says so.

  6. Process actions signal

    Terminate, force kill, suspend, or resume a process. ProcessLama asks before it sends a destructive signal.

  7. Pins and subtree focus focus

    Pin the processes you check often, or narrow the view to one subtree.

  8. Snapshots snapshot

    Save the current tree, give it a name, export it, and open it again later.
