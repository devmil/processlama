Anleitung

Entfernte Hosts

ProcessLama zeigt die Prozesse anderer Rechner in eigenen Tabs. Es verbindet sich mit deinem OpenSSH-Client, kopiert ein kleines Hilfsprogramm auf den Host und überträgt den Prozessbaum zurück. Der Helfer läuft als dein SSH-Benutzer und verwendet nie sudo.

Voraussetzungen

  • Auf diesem Rechner: OpenSSH 8.9 oder neuer und eine Anmeldung per Schlüssel, die ohne Rückfrage funktioniert (ein Schlüssel im Agent oder einer ohne Passphrase). ProcessLama startet ssh mit BatchMode=yes und StrictHostKeyChecking=yes: Verbinde dich einmal mit ssh <alias> in einem Terminal, um dem Host-Schlüssel zu vertrauen.
  • Linux-Hosts: x86_64 oder arm64 mit glibc 2.34 oder neuer (zum Beispiel Ubuntu 22.04, Debian 12, RHEL 9).
  • macOS-Hosts: Apple Silicon oder Intel, macOS 13 oder neuer.

Deine ~/.ssh/config

ProcessLama speichert nur einen Host-Alias. Benutzernamen, Ports, Schlüssel und Jump-Hosts gehören in die ~/.ssh/config:

Host build-box
    HostName build-box.example.net
    User deploy
    IdentityFile ~/.ssh/id_ed25519

Host db-internal
    HostName 10.0.4.12
    User ops
    ProxyJump bastion

Prüfe, dass ssh <alias> true ohne Rückfrage zurückkehrt, und verwende dann den Alias in ProcessLama.

Einen Host hinzufügen

Klick auf + am Ende der Tab-Leiste (Strg+T, unter macOS ⌘T) und wähle Entfernten Host hinzufügen …. Gib den Alias ein und klick auf Verbindung testen. Nach dem Speichern öffnet sich der Host in einem Tab. Fehlt der Helfer, zeigt ProcessLama Pfad, Version, Größe und Prüfsumme und fragt vor der Installation, sofern du Helfer automatisch installieren nicht eingeschaltet hast.

Der Helfer liegt auf dem Host unter ~/.local/lib/processlama/, sein Icon-Cache unter ~/.cache/processlama/.

Häufige Probleme

  • Home-Verzeichnis mit noexec: Aus einem mit noexec eingebundenen Home-Verzeichnis kann der Helfer nicht starten. ProcessLama installiert nirgendwo anders.
  • Login-Skripte: Text, den die ~/.bashrc ausgibt, wird übersprungen; ein Skript, das Eingaben liest, verhindert aber den Start des Helfers. Schütze interaktive Teile mit case $- in *i*) ;; *) return ;; esac.
  • Nur deine Prozesse: Hosts mit hidepid=2 verbergen die Prozesse anderer Benutzer; der Tab weist darauf hin.

Netzwerkwerte auf Linux-Hosts

Netzwerkwerte pro Prozess brauchen den ProcessLama-Netzwerkdienst auf dem Host. Rechner mit dem RPM oder DEB von ProcessLama haben ihn bereits. Für andere Hosts führt ihn die Download-Seite unter „Netzwerkdienst für entfernte Linux-Hosts“. In einem entfernten Tab kopiert Installationsbefehl kopieren im Netzwerk-Hinweis einen Befehl, den du auf dem Host ausführst; ProcessLama selbst führt nie sudo aus.

macOS-Hosts

Eine SSH-Sitzung auf macOS hat keine Datenschutzfreigaben. Für Prozesse anderer Benutzer, auch für root, zeigt der Inspektor Dateien, Sockets und Threads als eingeschränkt; die Sicherheitsdetails bleiben verfügbar. Deine eigenen Prozesse zeigen alles.

Wenn die Verbindung abbricht

Der Tab behält seinen letzten Messwert und markiert ihn mit Uhrzeit und Grund als veraltet. ProcessLama verbindet sich nach 2, 5, 15 und 30 Sekunden neu, danach jede Minute für bis zu zehn Minuten. Ein Verbindungsabbruch lässt keinen Prozess als beendet erscheinen.

Den Helfer entfernen

Öffne unter Einstellungen → Entfernte Hosts das Menü des Hosts und wähle Helfer vom Host entfernen …. Oder führe ssh <alias> 'rm -rf ~/.local/lib/processlama ~/.cache/processlama' aus.

Datenschutz

ProcessLama speichert nur den Alias und was der Helfer zuletzt gemeldet hat (System, Architektur, Helferversion). Es speichert keine Benutzernamen, Ports, Schlüssel oder Passwörter, und seine Protokolle enthalten keine Host-Namen oder Aliasse.
